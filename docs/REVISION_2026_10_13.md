## Current method

`M3=max(view absolute SHAP mass)/total absolute SHAP mass`. Reduced M4 is `(1-p_main)*max(Net_Behavioral,0)/total absolute SHAP mass`. Full M4 is `max(0,p_Behavioral-p_main)`. Ratios return zero at mass ≤1e-9. Fusion averages the two right-ECDF ranks computed from 500 benign reference inputs. Each score has its own model-specific threshold from 2,000 benign calibration inputs. Alerts use strict `score > tau`. A target calibration FPR is not a future FPR guarantee.

## New evidence and reproduction

Run commands from the project root. The scientific scripts use `.venv/Scripts/python.exe -X utf8`. Document authoring uses the bundled Codex Python because it provides `python-docx`; see `scripts/build_revision_report_docx.py`.

1. `scripts/analyze_primary_revision.py --out <fresh-directory>` recreates component, denominator, catch/miss, rank-correlation and fixed-model source-ID bootstrap results from the old paired scores. This is score reproduction, not retraining. It refuses an occupied output directory.
2. `scripts/run_revision_supplement.py --stage calibration` recomputes all old thresholds, saves new calibration caches, parse-flag sensitivities, inverse STRIP and the clean shadow baseline. Existing complete cells resume only with the same protocol and input hashes.
3. `scripts/prepare_revision_validation.py` freezes 1000 benign and 1000 malware per dataset using source metadata before prediction, excluding known local history. V3 requires the pinned local archives and source audit SQLite database.
4. `scripts/run_revision_validation.py --stage fresh` evaluates all 54 fixed models on the new IDs without retuning. Its early adaptive branch is withdrawn and must not be used. Use the next command for the actual Structural-only experiment.
5. `scripts/run_revision_adaptive.py --stage adaptive` uses its own namespace and protocol. It keeps the original trigger and permits proposals only in remaining Structural whitelist columns, at most 32 queries per sample and 100 fresh malware IDs per confirmed restricted model. Do not interpret a bounded optimizer as proof of adaptive robustness.
6. `scripts/run_revision_supplement.py --stage latency` measures classifier/core/STRIP/suite independently on the same 100 inputs per cell after warm-up. Avoid concurrent scientific work when measuring timing.
7. `scripts/validate_revision_binary.py` compiles and executes only its reviewed self-built benign fixture; no dataset sample is executed. It tests two timestamp edits and one benign overlay with four functional inputs, and records complete feature differences. V3 parsing requires `.[binary-v3]`; V2 remains a modern-LIEF experiment without legacy identical-byte parity.
   A read-only example is `.venv/Scripts/python.exe -X utf8 scripts/extract_revision_pe.py --schema V3 --input outputs/revision_2026_10_13/binary_validation/ReviewedBenignFixture.exe --out outputs/revision_2026_10_13/binary_validation/example_v3.npy`. This does not execute the input or certify it as safe.
8. `scripts/summarize_revision.py` combines complete evidence for the Word builder. `scripts/build_revision_delivery_notes.py` produces the Vietnamese feedback ledger and preservation record.

`scripts/build_revision_source_map.py` adds an explicit claim/source/evidence matrix and descriptive calibration-versus-final benign score-tail plots for TADR, X-R and X-F. These retain each model's own threshold and do not treat repeated source IDs as independent observations. Word layout is checked using `scripts/render_revision_word_pages.ps1`, which renders actual Word Print Layout page metafiles to PNGs; the packaged LibreOffice renderer is unavailable on this machine and native Word PDF export stalled.
