## Application and model contract

Reduced combines VMC and BGS reference ranks. Full combines VMC with BPG, the clean Behavioral probability gap. Only the Behavioral auxiliary prediction is used by selected primary Full inference. The current bundle constructor/loader nevertheless requires all three clean view-model files when a Full view-model dictionary is supplied; primary training also creates all three. Keep that physical bundle contract separate from the score formula.

Scoring a calibrated bundle needs neither retraining nor the original fit data. Building the original auxiliary models used 200,000 labelled benign/malware fit records, separate from 500 benign reference and 2,000 benign calibration records. The calibration target bounds only the observed calibration FPR; the trigger comparison is strict `score > threshold`.

The dashboard supports PE files up to 50 MiB and compatible vector/raw-JSON inputs. It parses PE files in a separate worker, then uses the vector analysis route when the API is enabled. Extraction is not binary execution, and worker separation is not a complete security sandbox. V2/V3 fixture checks are not original-dataset binary parity validation. PostgreSQL user/role tables do not implement authentication.

The README installation now includes both `service` and `binary-v3` extras. Docker/service checks in the existing handoffs are historical; this documentation update did not start or rebuild the stack, rerun training or claim fresh acceptance on another physical machine.
